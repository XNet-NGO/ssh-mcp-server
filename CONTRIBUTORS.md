## How to Be Listed

Contributors who make significant contributions to the project will be added to this file. Contributions include:

- Code contributions (features, bug fixes, improvements)
- Documentation improvements
- Testing and quality assurance
- Bug reports and issue triage
- Community support and advocacy

To be listed, your contributions should be:
- Merged into the main branch via pull request
- Significant in scope or impact
- Properly attributed in commit history
